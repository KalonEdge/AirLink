# Security

If you believe you've found a security issue in AirLink, please report it privately rather than in public, using the contact form at [kalonedge.com/contact](https://kalonedge.com/contact/).

Please include the version of AirLink (AirLink › About AirLink), your version of macOS, and the steps that show the issue.

## Supported versions

Security fixes go into the latest release. AirLink installs updates by itself, so keeping Update automatically on (Settings › General) keeps you protected.
